# 10 · 前端开发约束（v2.0 天空信标，强制执行）

> 地位：与 `04-API接口设计`、`05-安全设计` 同级的前端强制规范。
> 违反本约束的代码不得合并。评审时按本文逐条核对，未列明的新情况按“最接近的已有规则”类推，
> 仍无可类推时由维护者在 PR 中裁定并回写本文。
>
> 生效版本：v2.0（天空信标重构）。设计语言与页面蓝图见
> [06-前端设计规范](./06-前端设计规范.md)；v1.0 dense 企业风约束已作废。

## 1. 技术栈锁定

| 项 | 选型 | 说明 |
| --- | --- | --- |
| 框架 | Vue 3（`<script setup>` + Composition API） | 禁止 Options API 新代码；禁止 `export default { components }` 混写 |
| 构建 | Vite 6 | 分包策略见 §9，禁止随意新增 manualChunks |
| 路由 | Vue Router 4（嵌套路由 + 全局守卫 + Transition 转场） | 管理端子页必须是嵌套路由，禁止组件内 `v-if` 切换页面 |
| 状态 | Pinia（`src/stores/`） | 跨组件状态必须进 store；禁止模块顶层 `reactive + setInterval` 自启动 |
| 图表 | ECharts（按需引入）+ 轻量 SVG（卡片级） | 卡片内仪表/迷你走势用 `GaugeRing/SparkLine`；页面级大趋势用 `TrendChart`；禁止全量 `import 'echarts'` |
| 语言 | JavaScript（ES2022） | 新增文件用 JSDoc 标注关键类型；迁移 TS 之前禁止无校验的深层访问（`a.b.c` 前必须判空或用可选链） |
| 包管理 | npm（`package-lock.json` 必须提交） | 新增依赖必须在 PR 中说明理由与体积影响 |

禁止引入：组件库（Element Plus / Ant Design Vue / Naive UI 等）与动画库
（GSAP / motion / animate.css 等）——动效用 `motion.css` keyframes + `composables/` 自建；
若未来页面超过 20 个或表单复杂度翻倍，需另起 ADR 评审后方可引入组件库，且只允许按需引入。

## 2. 目录结构（强制）

```
web/src/
├── api/            # 网络层唯一出口（http.js + admin.js）。组件/store 禁止直接 fetch
├── stores/         # Pinia：monitor（监控数据）/ admin（管理端）/ ui（界面偏好）
├── composables/    # useTween（数字补间）/ useSpotlight（v-spotlight 指令）
├── layouts/        # AppShell.vue（浮动侧栏+顶栏+主内容+页脚）。禁止各页自造骨架
├── views/
│   ├── monitor/    # 公开监控页（OverviewView.vue）
│   ├── admin/      # 管理端（AdminLayout + Servers/Settings/Security/Audit/Login/Setup + ServerEditorModal）
│   └── error/      # NotFoundView.vue（404）。禁止通配符静默回首页
├── components/
│   ├── aurora/     # AuroraBackground.vue（极光背景，纯装饰）
│   ├── ui/         # 原子组件：TweenNumber/StateEmpty/StateError/StateSkeleton/ConfirmDialog
│   ├── charts/     # TrendChart（ECharts）/ GaugeRing + SparkLine（SVG 卡片级）
│   └── monitor/    # NodeCard（节点卡片）
├── router/         # 路由表 + 全局守卫（鉴权/初始化分流/已登录重定向）
├── utils/          # format.js（格式化函数，后端接入后复用）
└── styles/         # 按顺序引入：tokens → base → motion → components → layout → views
```

> 注：M0.5 的 `admin/store.js`（localStorage 模拟后端）与 `mock/`（原型模拟数据）
> 已在 M1 后端落地时删除，`MOCK_MODE` 同步移除；`api/admin.js` 全方法直调 `http.*`，
> `stores/monitor.js` 数据源为公开 API + SSE。

新增规则：

1. 新页面必须先在 `router/index.js` 注册路由 + `breadcrumb`，再写视图文件；
2. 新通用组件必须放入 `components/ui/` 并在本约束 §5 登记命名；
3. 新样式必须先查 `tokens.css` 是否有现成令牌，没有则先加令牌再使用；
4. 新动效必须先查 `motion.css` 是否有现成 keyframes/Transition 类，没有则加在 motion.css
   并遵守 §3 动效预算；禁止在组件 `<style>` 里新造全局 keyframes（scoped 组件内私有动画除外）；
5. ~~`admin/store.js`（localStorage 模拟后端）是**临时 mock 实现**，只允许 `api/admin.js`
   引用；M1 后端就绪后整体替换，视图层禁止直引。~~（M1 已删除，后端直调 `http.*`；视图层仍禁止直调网络。）
6. 管理入口隐藏：公开 UI（侧栏/顶栏/404/公开页）禁止出现任何管理链接或鉴权按钮，
   管理员直访 `/admin` 进入；`api/auth.js` 为公开首屏唯一鉴权出口（status/setup/login/logout/
   改密 + 密码强度 + 30 秒缓存），不得引用节点/凭据/种子数据；`api/admin.js` 与
   `stores/admin.js` 仅允许管理端懒加载 chunk 引用；管理子页必须路由懒加载。

## 3. 设计令牌与动效预算（`styles/tokens.css` 唯一真相源）

- 所有颜色、字阶、间距、圆角、阴影、层级必须引用 `--bt-*` 变量。
  禁止在组件 `<style>` 或行内样式中写死色值，白色也必须用 `var(--bt-bg-card-solid)` 等令牌；
  例外：ECharts 配置项不接受 CSS 变量，允许写 hex 色值，但必须与 tokens 中的品牌/语义色一致
  （`#0EA5E9 / #8B5CF6 / #F59E0B / #10B981 / #F43F5E`）并在 TrendChart 的 hexA() 中转 rgba。
- 间距必须使用 `--bt-space-*` 的 4pt 网格；出现 `13px / 17px` 这类非网格值必须注释理由。
- 圆角：卡片 `--bt-radius-lg(16)`、弹窗/大容器 `--bt-radius-xl(20)`、输入/按钮 `--bt-radius-md(10)`、
  标签/按钮 `--bt-radius-pill`；禁止混入 v1 的 6px 旧档。
- 阴影：卡片 `--bt-shadow-card`；悬停 `--bt-shadow-hover`；弹窗/下拉
  `--bt-shadow-modal/dropdown`；主按钮光晕 `--bt-shadow-glow-brand`。
  阴影一律走 tokens 的蓝紫调彩色投影，禁止自造纯灰投影。
- **玻璃是设计语言不是违禁品**：`backdrop-filter: blur(18px~28px) saturate(150%~180%)`
  允许用于卡片/侧栏/顶栏/弹窗/toast；但必须配 `--bt-glass-hi` 顶部高光与
  `--bt-glass-border` 半透明描边，禁止裸半透明色块冒充玻璃；
  同时必须提供 `@media (prefers-reduced-transparency: reduce)` 降级为实色底。
- **动效预算（v2.0，强制）**：
  - 入场（`.bt-enter`）：位移 ≤16px、时长 ≤680ms、步进 55ms、`--i` 上限 11；
  - 交互反馈（hover/press/选中）：≤260ms，弹簧曲线用 `--bt-ease-spring`；
  - 弹窗/转场：≤420ms；数字补间 800ms（`useTween`，禁止自行 rAF）；
  - 时长/缓动只允许取 `--bt-duration-*` + `--bt-ease*` 令牌；禁止私自新增全局时长与缓动；
  - 允许：极光背景漂移、状态脉冲、骨架 shimmer、按钮 is-spin、进度光线、
    sparkline 描画、GaugeRing 补间、指针辉光、页面/弹窗/toast/list Transition；
  - 禁止：3D 倾斜、滚动视差、无限循环入场（脉冲/漂移/ shimmer/ spin/进度条除外）、
    强制打开页面时的整页动画序列、无视 `prefers-reduced-motion` 的任何动画。

## 4. 布局骨架（`layouts/AppShell.vue` + `styles/layout.css`）

1. 所有页面共用 `AppShell`：浮动玻璃侧栏（240px，12px 头边距）+ 悬浮玻璃顶栏 + 主内容 + 页脚。
   禁止页面自带第二套侧栏或顶栏。
2. 导航选中态用“白色药丸 + 彩色柔影 + 品牌渐变文字”，禁止实心大色块选中。
3. 路由转场：顶层 RouterView 用 `<Transition name="page" mode="out-in">`（组件需单根），
   管理端子页用 `name="page-sub"`；禁止无 key 的整块 v-if 切页。
4. 断点：`1080px` 侧栏收为 76px 图标轨；`720px` 侧栏变抽屉 + 顶栏出现菜单按钮。
   新增页面必须在这三个宽度下无横向滚动（表格除外，表格用 `.bt-table-wrap` 横滚）。
5. 页脚必须保留隐私声明（“公开页面不展示 IP 及敏感信息”）。
6. 背景只有一套：`AuroraBackground` 挂在 `App.vue`，页面禁止再叠背景色/背景图。

## 5. 组件清单与命名（`bt-*` 前缀是强制的）

| 组件 | 文件 | 用途 | 禁止事项 |
| --- | --- | --- | --- |
| 按钮 | `.bt-btn(.--primary/.--default/.--ghost/.--danger/.--danger-ghost/.--sm/.--block)` | 全站唯一按钮样式 | 禁止 `<button>` 裸写样式；禁止无 `type="button"` 的按钮 |
| 输入 | `.bt-input/.bt-textarea/.bt-select/.bt-field/.bt-check` | 表单控件 | 禁止裸 `<input>`；label 必须用 `.bt-field__label` 并关联控件 |
| 卡片 | `.bt-card(.--hover)/(.card__head/.card__body)` + `.spot` + `v-spotlight` | 玻璃容器与可交互卡 | 禁止自造 `.glass-card` 等旧类名；可交互卡必须 `--hover` 或 `spot` 之一 |
| 标签 | `.bt-tag(.--success/.--warning/.--danger/.--info/.--outline)` | 状态/分类 | 状态必须“颜色 + 文字/图标”双通道，在线态用 `.pulse-dot` |
| 表格 | `.bt-table-wrap > .bt-table` | 数据列表 | 必须有 `<caption>`；表头 `<th scope="col">`；数字列右对齐 `.num`；sticky 表头 |
| 工具条 | `.bt-toolbar(.toolbar__info/.toolbar__actions)` | 页头操作区 | 主按钮放右侧 actions，禁止散放 |
| 空态/错误/骨架 | `StateEmpty/StateError/StateSkeleton` | 三态覆盖 | 每个列表页必须同时处理 loading / empty / error |
| 确认弹窗 | `ConfirmDialog`（外层 `<Transition name="modal">`） | 危险操作 | 禁止 `confirm()`；必须 `role=dialog + aria-modal + ESC + 焦点管理` |
| 弹窗 | `.bt-modal-mask/.bt-modal(.--lg)` | 通用弹窗 | 同上；必须包 `<Transition name="modal">` |
| 提示条 | `.bt-alert(.--error/.--success/.--info)` | 表单内反馈 | 禁止 `alert()`；错误用 `role=alert` |
| 分段控件 | `.bt-seg/.bt-seg__item[aria-pressed]` | 筛选切换 | 必须用 `aria-pressed` 表达选中 |
| 数字补间 | `TweenNumber`（`useTween`） | KPI/仪表数字 | 禁止组件内自写 rAF 补间；`format` 必须来自 `utils/format.js` |
| 趋势图 | `TrendChart` | 页面级大趋势 | 必须传 `label`（a11y）；`yFormatter` 统一单位；调用方自带图例（含实时值） |
| 仪表环 | `GaugeRing` | 卡片级仪表 | 禁止在卡片里 mount ECharts 实例；阈值色自动切换，禁止写死单色 |
| 迷你走势 | `SparkLine` | 卡片级走势 | 必须带 `title + role=img`；颜色传 hex（配合渐变填充） |
| 背景 | `AuroraBackground` | 全局极光底 | 禁止改动其 z-index/pointer-events；禁止在业务组件内复用其光斑类 |

`AppIcon`：新增图标必须在该文件登记，16 画布 / stroke 1.5 / currentColor，
禁止 emoji、禁止外链图标字体。

## 6. 路由与鉴权

1. 管理端子页必须是嵌套路由（`/admin/servers|settings|security|audit`），支持深链与刷新保持。
2. 全局守卫顺序：未初始化 → `/admin/setup`；未登录 → `/admin/login?redirect=`；
   已登录访问 login/setup → 重定向 `/admin/servers`。`status()` 缓存收敛在 `api/auth.js`
  （`getCachedStatus/resetAuthCache`，30 秒复用；登录/初始化/登出后清缓存），路由层禁止自建缓存。
3. `status()` 结果缓存 30 秒（`router/index.js` 内），禁止每次跳转都请求。
4. 通配符路由必须进独立 `NotFoundView`（404），禁止 `redirect: '/'`。
5. 面包屑由路由 `meta.breadcrumb` 驱动，新增管理子页必须配三级面包屑
   （总览 / 管理面板 / 当前页）。

## 7. 数据层

1. 网络请求唯一出口 `api/http.js` 的 `request()`：超时 8s + AbortController +
   非 GET 自动附 `X-CSRF-Token`（读 `bt_csrf` Cookie）+ `{code,msg,data}` 解包（code≠0 按 04 错误码映射抛错）+
   错误归一化（`ApiError{code,message,status,retryable}`）+ 指数退避重试。
   禁止在组件/store 里直接 `fetch`。
2. 管理端调用统一走 `api/admin.js`（门面，直调后端 `/api/v1/admin/*`；M0.5 的
   MOCK_MODE 委托链已在 M1 移除）。store 与视图只调门面，零改动约束保持。
3. 监控数据唯一来源 `stores/monitor.js`：
   - 不可见标签页暂停轮询（`document.hidden`），回到可见立即刷新一次；
   - 定时器必须在 `stop()` 中清理，禁止模块级 `setInterval` 常驻；
   - `status: loading|ready|error` 驱动三态 UI，失败必须可重试；
   - 展示层的数字滚动只允许走 `TweenNumber/useTween`（与轮询解耦）。
4. 轮询间隔常量集中在 store 顶部（当前 10s），禁止散落魔法数字。
5. 凭据字段（密码/私钥/口令）永不回显：读取接口返回 `has_password/has_key` 标记，
   编辑时留空 = 保留原值（`ServerEditorModal` 已实现，新增凭据表单必须同构）。

## 8. 可访问性（a11y，合并门槛）

合并前必须逐项自查：

- [ ] 所有 `<button>` 显式写 `type`（提交按钮除外）；
- [ ] 图表/仪表/走势带 `role="img" + aria-label`（含最新值文案）；
- [ ] 状态不只依赖颜色（离线 = 虚线描边 + 降饱和 + “离线”文字 + 静止点；错误用图标 + 文字）；
- [ ] 弹窗 `role=dialog + aria-modal + ESC 关闭 + 打开时聚焦 + 关闭后焦点返回`；
- [ ] 全局 `:focus-visible` 焦点环不得删除；
- [ ] `skip-link`（跳到主内容）不得删除；
- [ ] 表格有 `caption`，表头有 `scope`；
- [ ] 表单 `label` 与控件关联，必填项标 `*` 且有文字说明（不只红色）；
- [ ] 对比度：正文/次要文本 ≥ 4.5:1（`--bt-text-*` 在浅色极光底上均满足，勿自创浅灰）；
- [ ] `prefers-reduced-motion` 全局兜底不得删除（含 `useTween` 的直接落位分支）；
- [ ] `prefers-reduced-transparency` 玻璃降级不得删除（含侧栏/顶栏/卡片/弹窗）。

## 9. 性能预算（构建产物红线）

| 包 | 上限（gzip） | 当前（v2.0） | 说明 |
| --- | --- | --- | --- |
| 业务 `index` | ≤ 45 KB | ~33 KB | 超出需拆分路由懒加载 |
| 框架 `vendor`（vue/router/pinia） | ≤ 45 KB | ~41 KB | 升级框架后复核 |
| 图表 `echarts` | ≤ 200 KB | ~175 KB | 只允许 line/grid/tooltip；新增图表类型需评估体积 |
| 样式 `index.css` | ≤ 12 KB | ~9 KB | 新增全局样式超 1KB 需说明 |

- ECharts 必须按需引入（`echarts/core + charts + components + renderers`），
  禁止 `import * as echarts from 'echarts'` 全量引入。
- 卡片级高频组件禁止 mount ECharts 实例（用 SVG 的 GaugeRing/SparkLine）。
- 首屏 ECharts 实例 ≤ 2 个（总览页吞吐 + 功耗），新增图表需懒加载。
- 极光背景与脉冲等装饰动画只允许 transform/opacity（合成层）；`filter: blur()` 只允许
  用在 `.aurora__blob` 与玻璃 `backdrop-filter`，禁止给滚动内容新增逐帧 filter 动画。
- 指针辉光（v-spotlight）必须 rAF 合帧写 CSS 变量，禁止直接在 pointermove 里改样式布局属性。
- `vite.config.js` 的 manualChunks（`echarts/vendor` 分包）禁止随意改动。

## 10. 代码风格（轻量，无 lint 工具链时的手工红线）

1. Vue 文件统一 `<script setup>`，props 必须声明类型与默认值，复杂对象用 JSDoc 注释形状；
2. 魔法数字必须命名常量（阈值 60/85、轮询 10s、历史窗口 40 点、补间 800ms 等已有命名，
   新增不得散落）；
3. 格式化函数只允许放在 `utils/format.js`，禁止组件内私自 `toFixed` 拼单位
   （`TweenNumber.format` 与图表 `yFormatter` 复用同一批函数）；
4. 样式文件职责：`tokens`（变量）→ `base`（resets/焦点/滚动条）→ `motion`（keyframes/Transition 类）→
   `components`（原子）→ `layout`（骨架）→ `views`（页面）。
   跨层引用禁止反向（原子组件样式不得依赖页面样式）；
5. 旧类名前缀（`glass-card`、`hero-card`、`server-card`、`side-*`、`stub-*`、`v-tilt`、
   `UsageRing`）已全部删除，禁止复活；全局搜索到即视为违规；
6. 注释只写“为什么”（约束来源、后端对接 TODO(Mx)、a11y 理由），不写“是什么”。

## 11. 安全与隐私（前端侧）

1. 公开页永不渲染 IP、主机名、SSH 用户名、指纹、私有备注（NodeCard/Overview 已脱敏，
   新增公开字段必须经评审）；
2. 管理端敏感字段（公网 IP、指纹、私有备注）必须标注“（私有）/ 仅管理端可见”；
3. 密码/私钥输入框必须 `autocomplete` 正确（`current-password/new-password/off`）；
4. 审计删除/重置/改密等操作必须走 `ConfirmDialog`，且后端返回前按钮 `busy` 禁用防重放；
5. `index.html` 保留 `referrer=no-referrer`；新增外链必须 `rel="noopener noreferrer"`。
