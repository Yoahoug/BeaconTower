# BeaconTower（信标塔）开发方案

> 面向个人/小团队的自托管服务器监控面板：亮色卡片式前端，面板通过 SSH 直连被监控服务器采集指标（无 Agent），单容器部署，公开页面不暴露 IP 等敏感信息。

## 一句话架构

```
浏览器 ── HTTPS ──> [BeaconTower 容器]  ── SSH(加密) ──> 被监控服务器 A/B/C…
                     Go 后端 + SQLite       定时拉取指标与系统画像，无需在被监控机安装任何东西
                     内嵌 Vue3 静态前端
```
