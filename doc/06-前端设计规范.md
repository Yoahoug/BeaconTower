# 06 · 前端设计规范（iPhone 液态玻璃风格）

> 原型已实现：`web/`（Vue 3 + Vite）。本文档是设计与后续实现的对照规范。
> 设计基准：**iOS 26 Liquid Glass 液态玻璃**。实现规范依据 [ref-mac-style-guide.md](./ref-mac-style-guide.md)（mac-style-guide 指南）与社区 Liquid Glass CSS 配方（dev.to/kevinbism、theplusaddons、LogRocket），配方按亮色面板场景调校。

## 1. 设计原则

1. **玻璃质感 = 低填充 + 高饱和 + 亮边 + 内发光**：卡片白底仅 48% 透明 + `blur(14px) saturate(180%)`，白色亮边框（78%）+ inset 顶部高光 + 底部内发光 + 双层蓝灰投影；
2. **壁纸必须有色彩结构**：蓝/绿/紫/琥珀四团柔光固定附着在页面底，玻璃 blur 的就是这层——色彩越明确玻璃越"透"（纯灰底上玻璃会退化成磨砂色块，指南 §3.2 同理）；
3. **层次靠投影，不靠彩色描边**：悬停只加重投影 + 弹性上浮；
4. **Apple System Colors**：蓝 `#007AFF` / 绿 `#34C759` / 橙 `#FF9500` / 红 `#FF3B30`；
5. **统一缓动**：常规过渡 `cubic-bezier(.32,.72,0,1)`；弹性交互（徽标悬停、卡片悬停）用带轻微过冲的 `cubic-bezier(.34,1.3,.5,1)`；
6. **零 emoji**：全部内联 SVG（16×16 线性符号 `stroke: currentColor`）；
7. **数字用等宽数字**（`tabular-nums`），补间不抖动。

## 2. 页面结构（`App.vue` 的 `.app-shell`）

```
┌─ 壁纸：4 团彩色柔光（蓝/绿/紫/琥珀）+ 颗粒点阵 + 顶部暗角，fixed 附着 ─┐
│ ┌─ 侧边栏 216px（液态 vibrancy：白 55% + blur(40px) sat 180%）─┐      │
│ │ 🛟 BeaconTower 信标塔监控（徽标带弹性悬停）                     │      │
│ │ 监控 / ● 总览(蓝色药丸+内高光) / 服务器¹ 历史¹                  │      │
│ │ [在线 2/3] [总吞吐 ↑↓] ← 状态小件（玻璃）                       │      │
│ └────────────────────────────────────────────────────────────┘      │
│ 内容区：                                                            │
│  英雄面板（玻璃大卡）：总数/在线/上行/下行 大数字 + 全网吞吐双线走势图   │
│  服务器卡片（三列，min 300px，一屏看完）：三仪表(56px) + CPU走势 + 网速 │
│         + TCP/UDP/进程/虚拟化信息行 + 页脚，离线卡置灰                 │
└─────────────────────────────────────────────────────────────────────┘
¹ 规划中（灰色禁用态 + 「规划中」角标）
```

- 面向 **3~10 台节点的真实规模**设计：紧凑三列卡片（`minmax(300px,1fr)`），一屏看完所有节点状态，信息完整不省略；
- 卡片地区行在 `region_source=auto` 时前置蓝色定位图标（`AppIcon pin`，11px），悬停提示"地区由公网 IP 自动定位（IP 不公开）"，`manual` 时无图标；
- 英雄面板与服务器卡片都支持 `v-tilt` 倾斜 + 流动光斑；
- 管理后台不设公开入口：`/admin` 为隐藏后台，仅地址直达；
- 页脚以透明白分隔线收尾。

## 3. 液态玻璃配方（核心令牌，见 `src/styles/main.css`）

| 令牌 | 值 | 说明 |
| --- | --- | --- |
| `--glass-fill` | `rgba(255,255,255,.32)` | 卡片低填充白底（高度透明，壁纸色彩明显透出） |
| `--glass-blur` | `blur(14px) saturate(180%)` | 磨砂 + 提升透出的色彩饱和度 |
| `--glass-edge` | `rgba(255,255,255,.72)` | 白色亮边框 |
| `--glass-shadow` | inset 顶部高光 + inset 底部内发光 + 0.5px 白勾边 + 双层蓝灰投影 | 静止态 |
| `--glass-shadow-hover` | 各层加强 + 投影加深 | 悬停态 |
| `--side-fill` / `--side-blur` | 白 55% / `blur(40px) saturate(180%)` | 侧栏 vibrancy 档 |
| `.server-card::before` 等镜面层 | `radial-gradient(120% 55% at 30% 0%)` 白 42%→透明 | 顶部偏左镜面高光（玻璃曲率感） |
| `--radius` | `18px` | 玻璃卡圆角（iOS 卡片感） |
| `--ease-mac` / `--ease-pop` | `cubic-bezier(.32,.72,0,1)` / `cubic-bezier(.34,1.3,.5,1)` | 常规 / 弹性 |

状态徽章/网速内衬也统一为玻璃小件（白 35~42% + 0.5px 白勾边），选中药丸带内高光 + 深色 inset 底边（iOS 按钮配方）。

## 4. 动效清单

| 动效 | 实现 | 说明 |
| --- | --- | --- |
| **卡片 3D 倾斜** | `v-tilt` 指令（`src/directives/tilt.js`）：光标位置驱动 `rotateX/rotateY`（最大 4.5°，`perspective(900px)`），跟随阶段 0.08s linear 跟手，离开后 0.5s `--ease-pop` 弹性复位；同时上浮 4px | **核心悬停反馈**（液态玻璃"随移动反应"） |
| **流动光斑** | 倾斜时 `::after` 径向光斑跟随 `--mx/--my`（光标卡内坐标）移动，离开淡出 | 镜面高光随光标流动 |
| 卡片入场 | `rise-in` 0.5s：上移 14px + scale 0.98→1，交错 40ms；**fill-mode 用 backwards** 释放 transform 给倾斜 | 入场与倾斜互不抢占 |
| 仪表画弧 | `GaugeRing` 挂载后从 0 画到目标值（0.9s），三仪表按卡片序错开 40ms、卡内错 90ms | 仅入场一次，平时不跳 |
| 数据刷新 | **每 10s 静默更新，无数字补间**；仪表 `stroke-dashoffset 0.6s` 平缓跟上 | 监控面板要沉稳，不做赛博跳动 |
| 时间戳 | "更新于 N 前"每 5s 一跳（`agoText` 按 5s 取整） | 低频、不干扰 |
| 侧栏/徽标 | `side-in` 滑入；品牌徽标悬停 `scale(1.08) rotate(-4deg)` 弹性 | 细节动效 |
| 离线置灰 | `opacity .55 + saturate(.3)` | 状态语义优先 |
| 系统偏好 | `prefers-reduced-motion`（v-tilt 直接不启用） / `prefers-reduced-transparency`（玻璃→实色白卡） | 无障碍 |

> 设计基调：**动效只用于交互反馈与入场，不用于持续吸引注意力**。数字常驻稳定，
> 数据每 10s 静默换一批（后端接入后由 SSE 驱动，节奏一致）。

## 7. 数据接入约定

- 原型用 `src/composables/useLiveServers.js` 模拟实时（3s 随机游走 + 900ms 数值补间）+ `src/mock/data.js`；
- 后端就绪后仅替换该 composable 实现（订阅 SSE `/api/v1/public/stream`，补间保留），组件层零改动；
- 字段结构即 04 文档 1.2 响应结构；紧凑容量 `fmtSizeShort`（`2G/340G/1.2T`）用于仪表标签。
