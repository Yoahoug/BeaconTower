# 06 · 前端设计规范（企业级 v1.0）

> v1.0 企业级重构已落地：`web/`（Vue 3 + Vite + Pinia + ECharts 按需引入）。
> 视觉从“液态玻璃消费风”收敛为“ dense 沉稳企业后台风”，强制约束见
> [10-前端开发约束](./10-前端开发约束.md)（合并门槛），本文只描述设计语言与页面蓝图。
> 旧玻璃配方已归档于 `doc/ref-mac-style-guide.md`，禁止在新代码中引用。

## 1. 设计原则

1. **信息密度优先**：12–13px 为主字阶，紧凑行高，表格行高 40px，一屏呈现更多节点与指标；
2. **沉稳实色**：白卡 + 1px hairline + 小圆角（12px/6px），层次靠描边与留白，不靠投影与透明；
3. **状态双通道**：颜色 + 文字/图标同时表达（离线 = 虚线边框 + “离线”徽标，不只置灰）；
4. **品牌克制**：品牌蓝 `#0A64E0` 只用于主按钮、选中强调条、链接；成功/告警/危险语义色各归其位；
5. **零 emoji**：全部内联 SVG（`AppIcon`，16 画布 / stroke 1.5 / currentColor）；
6. **数字等宽**（`tabular-nums`），刷新不抖动；
7. **动效只用于反馈**：悬停、弹窗、骨架 shimmer；禁止入场交错动画、3D 倾斜、流动光斑。

## 2. 页面结构（`layouts/AppShell.vue`）

```
┌─ 顶栏 56px（白底 hairline，唯一 backdrop-blur）：面包屑 / 更新时间 / 全网徽标 / 管理员 ─┐
│ ┌─ 侧栏 224px（白底 + 右描边）─┐ ┌─ 主内容（max 1440px）──────────────────┐ │
│ │ BeaconTower 信标塔监控        │ │ 页面头：标题 + 描述 + 右侧操作          │ │
│ │ 监控 / 总览                   │ │ KPI 条（6 格，左侧 3px 状态条）         │ │
│ │ 管理 / 管理面板               │ │ 全网趋势（ECharts：吞吐双线 + 功耗单线） │ │
│ │ 在线 2/3 · 功耗 8.7W（小字）  │ │ 搜索 + 状态分段筛选                     │ │
│ └──────────────────────────────┘ │ 节点网格（min 340px，白卡）             │ │
│                                  └────────────────────────────────────────┘ │
└─ 页脚：隐私声明（公开页不展示 IP） + 版本 ──────────────────────────────────┘
```

- 断点：`1080px` 侧栏收为 64px 图标轨；`720px` 侧栏变抽屉 + 顶栏菜单按钮；
- 导航选中态：浅蓝底 + 左侧 3px 强调条（禁止渐变药丸）；
- 管理端无公开入口：侧栏只有“管理面板”入口，内部子页靠嵌套路由 + 下划线标签导航。

| 层级 | `--bt-z-modal-mask(60) / --bt-z-toast(80)` | 悬浮层秩序 |

## 4. 动效清单（克制）

| 动效 | 实现 | 说明 |
| --- | --- | --- |
| 悬停 | 卡片 `shadow-card → shadow-hover` 200ms | 无位移、无倾斜 |
| 弹窗 | `pop-in` 200ms（上移 10px + 淡入） | 只有管理端弹窗 |
| 骨架屏 | `shimmer` 1.4s 扫过 | 加载占位 |
| 仪表/走势 | 仪表过渡 400ms；ECharts 动画 300ms | 数据刷新平缓跟上 |
| 数据刷新 | 每 10s 静默更新，无数字补间 | 监控面板要沉稳 |
| 系统偏好 | `prefers-reduced-motion` 全局停动画 | 无障碍 |

## 7. 数据接入约定（M1 后端对照）

- 监控数据：`stores/monitor.js`（`tick()` 模拟 10s 刷新）→ 替换为 SSE
  `/api/v1/public/stream`；字段结构即 04 文档 1.2 响应结构；
- 管理接口：`api/admin.js` 门面（`MOCK_MODE=true` 委托 `admin/store.js`）→
  逐方法换成 `http.*` 调用，store 与视图零改动；
- 格式化：`utils/format.js`（`fmtBps/fmtWatts/fmtKwh/fmtCost/fmtGhz`）后端接入后复用，
  图表 `yFormatter` 必须复用同一批函数，禁止组件内私自拼单位。
