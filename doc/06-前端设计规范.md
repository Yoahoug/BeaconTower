# 06 · 前端设计规范（v2.0 天空信标 Sky Beacon）

> v2.0 全量重构已落地：`web/`（Vue 3 + Vite 6 + Pinia + ECharts 按需引入）。
> 设计语言从 v1.0「dense 企业后台风」升级为「天空信标」：**亮色 · 通透 · 灵动**——
> 浅色极光背景 + 白玻璃卡片 + 青蓝渐变品牌色 + 丰富而克制的动效系统。
> 强制约束见 [10-前端开发约束](./10-前端开发约束.md)（合并门槛），本文只描述设计语言与页面蓝图。
> 历史参考：`doc/ref-mac-style-guide.md`（液态玻璃配方归档）；v1.0 dense 规范已随本版作废。

## 1. 设计原则

1. **明亮通透**：浅色极光底（马卡龙光斑漂移）+ 白玻璃卡（backdrop-blur + 顶部高光 + 彩色柔影），
   拒绝暗黑赛博风；界面永远是「清晨天空」的观感；
2. **灵动动效**：数据补间、渐变仪表环、走势描画、指针辉光、脉冲状态点、spring 弹窗——
   动效用于表达「实时在跳动的生命力」，不是装饰堆砌；
3. **色彩分层**：品牌青蓝渐变（`#38BDF8 → #0EA5E9 → #6366F1`）只用于强调与主操作；
   语义色（绿/琥珀/玫红）负责状态；中性灰负责信息层级；KPI 卡各带色调（品牌/紫/绿/琥珀/玫红）；
4. **状态双通道**：颜色 + 文字/图标/动效同时表达（在线 = 绿色脉冲点 +「在线」徽标；
   离线 = 虚线描边 + 降饱和 + 灰色静止点 +「离线」文字）；
5. **零 emoji**：全部内联 SVG（`AppIcon`，16 画布 / stroke 1.5 / currentColor）；
6. **数字等宽**（`tabular-nums`）+ **数字补间**（`TweenNumber`，easeOutExpo 800ms），刷新不抖动且平滑滚动；
7. **动效预算**：入场 ≤16px / ≤680ms / 步进 55ms（上限 12 阶）；交互反馈 ≤260ms；
   全部尊重 `prefers-reduced-motion`（直接落位、不播放）。

## 2. 页面结构（`layouts/AppShell.vue` + `AuroraBackground`）

```
┌─ 极光背景（fixed，z-0）：4 团马卡龙光斑漂移 + 信标光束呼吸 + 点阵纹理 ──────┐
│ ┌─ 浮动玻璃侧栏 240px（12px 外边距，圆角 20）─┐ ┌─ 悬浮玻璃顶栏（sticky）─┐ │
│ │ 信标徽标（呼吸光环）BeaconTower 渐变字      │ │ 面包屑 · 更新时间 ·    │ │
│ │ 监控 / 状态总览（白底药丸选中态）           │ │ 全网徽标（脉冲点）·    │ │
│ │ 管理 / 管理面板                            │ │ 管理员登录/头像        │ │
│ │ 在线 2/3 · 功耗 8.7W（玻璃状态卡）         │ ├───────────────────────┤ │
│ └────────────────────────────────────────────┘ │ 主内容（max 1360px）  │ │
│                                                │ 页面头 / KPI 玻璃条   │ │
│                                                │ 全网趋势（ECharts）   │ │
│                                                │ 节点玻璃卡网格        │ │
│                                                └───────────────────────┘ │
└─ 页脚：隐私声明 + 版本 ───────────────────────────────────────────────────┘
```

- 断点：`1080px` 侧栏收为 76px 图标轨；`720px` 侧栏变抽屉 + 顶栏菜单按钮；
- 导航选中态：白色药丸 + 柔和彩影 + 品牌渐变文字/图标（左侧 4px 渐变条点缀）；
- 顶栏下 2px `.bt-progress` 刷新光线：数据轮询时青蓝渐变光线从左扫到右。

## 4. 动效清单（灵动而有预算）

| 动效 | 实现 | 说明 |
| --- | --- | --- |
| 极光背景 | 4 团光斑 `blur(72px)` 漂移（44/50/56/62s 不同周期）+ 信标光束呼吸 | 纯 transform/opacity 合成，零绘制开销 |
| 页面转场 | `page` Transition：淡入 + 上浮 14px（260ms）/ `page-sub` 管理端子页更轻 | 路由切换一次，轮询不重播 |
| 数字补间 | `useTween`（rAF + easeOutExpo 800ms）+ `TweenNumber` | 首屏从 0 计数到位；刷新时平滑滚动到新值 |
| 渐变仪表环 | `GaugeRing`：双 stop 渐变弧 + 端点发光球 + 补间弧长 | 阈值自动换色（绿→琥珀→玫红），内存紫/磁盘蓝可指定色调 |
| 走势描画 | `SparkLine`：`pathLength=1` 描画动画 1s + 面积渐显 + 末端脉冲球 | 入场描画一次；数据更新不重播 |
| 指针辉光 | `v-spotlight` 指令写 `--mx/--my`，`.spot::before` 径向光斑跟随 | KPI 卡与节点卡，rAF 合帧 |
| 首屏分层 | `.bt-enter`：淡入 + 上浮 16px + 缩放 0.985，420ms，步进 55ms（`--i` 上限 11） | 仅首屏/路由后一次 |
| 卡片悬停 | 上浮 4px + 描边泛青 + 彩影加深，260ms；OS 徽标微转 | 无 3D 倾斜 |
| 按钮 | 按压缩放 0.95 + spring 回弹；主按钮上浮 1px + 光晕 | 微交互 |
| 状态脉冲 | `.pulse-dot`：实心点 + 扩散环 2s 无限；离线静止 | 状态双通道之一 |
| 导航选中 | 白底药丸 + 彩影 spring；图标 hover 微放大 | 无滑动指示条动画 |
| 弹窗 | `modal` Transition：遮罩淡入 + 面板上浮 26px + scale 0.96→1（spring 420ms） | 进出都动画 |
| 轻提示 | `toast` Transition：底部上滑 14px + spring | `ui.notify` 触发 |
| 列表增删 | `list` TransitionGroup：淡入上浮 / 淡出上浮 | 节点管理行 |
| 品牌呼吸 | `.bt-beacon-glow`：徽标光环扩散 3.2s 无限 | 侧栏/登录页徽标 |
| 骨架微光 | `shimmer` 1.6s 扫过 | 加载占位 |
| 加载旋转 | `.is-spin` 0.9s | 按钮内图标 |
| 仪表/趋势 | 仪表补间 850ms；ECharts 更新 520ms `cubicOut` | 数据刷新平缓跟上 |
| 系统偏好 | `prefers-reduced-motion` 全局停动画 + `useTween` 直接落位 | 无障碍红线 |

## 7. 数据接入约定（M1 后端对照）

- 监控数据：`stores/monitor.js`（`tick()` 模拟 10s 刷新）→ 替换为 SSE
  `/api/v1/public/stream`；字段结构即 04 文档 1.2 响应结构；
- 管理接口：`api/admin.js` 门面（`MOCK_MODE=true` 委托 `admin/store.js`）→
  逐方法换成 `http.*` 调用，store 与视图零改动；
- 格式化：`utils/format.js`（`fmtBps/fmtWatts/fmtKwh/fmtCost/fmtGhz`）后端接入后继续复用；
  `TweenNumber` 的 `format` 与图表 `yFormatter` 必须复用同一批函数，禁止组件内私自拼单位。
